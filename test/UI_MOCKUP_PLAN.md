## 🎨 配色方案

### 颜色定义
```
主色调:
├─ 蓝色 (#3b82f6)     - 主要信息、链接
├─ 绿色 (#10b981)     - 成功、优秀、推荐
├─ 黄色 (#f59e0b)     - 警告、注意
├─ 红色 (#ef4444)     - 错误、问题
└─ 灰色 (#6b7280)     - 辅助信息

指标颜色:
├─ 100% ~ 90%  → 绿色 🟢 (优秀)
├─ 90% ~ 70%   → 黄色 🟡 (良好)
└─ <70%        → 红色 🔴 (需注意)
```

### 风险指示
```
🟢 绿色 - 无风险、优秀
🟡 黄色 - 低风险、轻微问题
🔴 红色 - 高风险、需关注
```
