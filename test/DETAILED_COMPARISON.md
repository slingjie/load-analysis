## 🔧 技术分析

### 为什么出现这些差异？

#### 问题1: 缺失日期统计不准确

**旧报告的问题**:
```python
# 旧逻辑: 基于365天固定窗口
end_day = max_timestamp.normalize()
expected_start = (end_day - 365天)
# 这样可能导致边界问题
```

**当前修正**:
```python
# 新逻辑: 期望日期范围
end_day = 2025-10-26
expected_start = 2024-10-27 (回推365天)
# 正确包含了2025-01-01

# 实际数据: 2024-11-01 ~ 2025-10-26
# 缺失: 2024-10-27 ~ 2024-10-31 (5天) + 2025-01-01 (1天) = 6天
```

#### 问题2: 异常值检测工具改进

**旧报告使用**: 可能的旧版检测逻辑
- 可能没有正确处理NaN
- 可能遗漏了某些异常

**当前使用**: 更新的检测逻辑
- 显式检测 `isna()` (发现1条空值)
- 显式检测 `== 0` (发现4条零值)
- 显式检测 `< 0` (发现5条负值)

#### 问题3: 记录数差异

旧报告: 34,560 条  
当前: 34,463 条 (-97)

**原因**:
```python
# 后端loader在读取时:
df = df.dropna(subset=["timestamp"])  # 丢弃NaN时间戳
# 这导致97条无效记录被过滤
```
