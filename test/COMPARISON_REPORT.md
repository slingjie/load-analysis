## 🔧 后端实现细节

### 数据加载流程 (loader.py)
```
1. 读取CSV文件 (支持多种编码)
2. 标准化列名 (中文→英文)
3. 自动识别时间戳和负荷列
4. 丢弃NaN时间戳记录 ← 这里导致34560 → 34463
5. 返回规范化的 DataFrame
```

### 质量报告流程 (quality.py)
```
1. 构建365天期望窗口 (基于数据最后一天回推)
2. 检测缺失日期 (期望日期中不在present_hours的)
3. 统计异常值:
   - Null: isna()
   - Zero: == 0
   - Negative: < 0
4. 返回结构化报告
```
