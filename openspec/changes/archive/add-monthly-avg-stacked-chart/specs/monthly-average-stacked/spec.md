## ADDED Requirements

### Requirement: 月度日平均负荷堆叠曲线
系统应提供一个“12个月日平均负荷曲线堆叠图”以对比不同月份的日内负荷规律。

#### Scenario: 多月对比展示
- 给定已清洗的小时级负荷点集（`timestamp`, `load`），
- 当用户进入负荷分析页面时，
- 则应呈现一个新图表：
  - 横轴为 0–23 点；
  - 纵轴单位为 kW；
  - 默认选中数据存在的月份；
  - 每个已选月份渲染一条折线，并按 ECharts `stack` 配置进行堆叠；
  - 支持单选/多选切换。

#### Scenario: 缺失数据与跨年
- 对任意月份-小时，若该小时存在 N 天数据，则该点取 N 天的平均值；
- 若无数据，则取 0；
- 若数据跨年，则同名月份合并计算（例如 2023-01 与 2024-01 均计入“1月”）。

#### Scenario: 交互与性能
- 图表支持窗口大小变化时自适应；
- 月份选择器应提供“全选/全不选”（在多选模式下）；
- 本功能不引入新依赖，ECharts 通过 CDN 动态加载。
