## 🔑 核心实现

### 工作原理（3 步）

```
1️⃣  推断采样步长
    └─ 计算所有间隔，找出现频率最高的值（众数）

2️⃣  检测缺失区间
    └─ 找出间隔 > 1.5 倍步长的位置

3️⃣  生成断轴配置
    └─ ECharts 自动渲染 zigzag 标记
```

### 代码位置

```typescript

const estimateStepMs = (() => { ... })

// 检测缺失（第 94-110 行）
const breaks = [];
for (let i = 1; i < points.length; i++) {
  const gap = points[i][0] - points[i - 1][0];
  if (gap > threshold) {
    breaks.push({ start, end, gap: 0 });  // 生成断轴
  }
}

// ECharts 配置（第 112-160 行）
xAxis: {
  type: 'time',
  breaks: breaks,  // 断轴配置
  breakArea: { zigzagAmplitude: 6 }  // 样式
}
```

## 💡 三分钟了解

**什么是断轴？**
> 当时间序列中有缺失数据时，图表不直接连接，而是在缺失位置显示 zigzag 标记，并标注缺失时间范围。

**为什么需要？**
> 直接连接会误导用户，让人以为数据是连续的。断轴能清晰表示数据状态。

**怎么实现？**
> 算法自动检测异常时间间隔，生成 ECharts `breaks` 配置，由 ECharts 渲染断轴效果。

**需要修改代码吗？**
> 不需要！已经完全实现和集成，直接使用即可。
