# M2 阶段测试计划 (Test Plan)

**版本**: v1.0  
**日期**: 2025-12-08  
**范围**: 功能测试、性能测试、兼容性测试

## 🎯 测试总体策略

### 测试类型

| 类型 | 范围 | 方式 | 责任人 |
|------|------|------|--------|
| **单元测试** | 工具函数、Hook 逻辑 | Jest + React Testing Library | 开发 |
| **集成测试** | 组件间交互、API 调用 | 手工 + 黑盒自动化 | QA |
| **UI 测试** | 界面渲染、样式布局 | 视觉对比 + 截图 | QA |
| **性能测试** | 计算时间、渲染帧率 | 计时 + DevTools | QA |
| **兼容性测试** | 浏览器、分辨率 | 多浏览器/设备 | QA |

### 验收标准

- ✅ 所有功能测试通过
- ✅ 性能指标达成
- ✅ 无浏览器兼容性问题
- ✅ 用户体验流畅无卡顿

### 测试套件 1: 批量容量对比 (StorageCyclesPage)

#### TC 1.1: 基础批量计算

**前置条件**:
- 已上传负荷数据
- 已配置储能参数（C-Rate=0.5, 效率=95%, DOD=90%）

**步骤**:
```
1. 打开【批量容量对比】Tab
2. 输入容量范围
   - 起始容量: 5000 kWh
   - 步长: 500 kWh
   - 步数: 5
3. 点击【🚀 开始批量容量对比】
4. 等待计算完成
```

**预期结果**:
```
✅ 显示进度条，从 0% → 100%
✅ 显示当前计算容量 (正在计算: 5500 kWh)
✅ 表格显示 5 个容量的结果:
   - 5000: 230 次/年, 750,000 元
   - 5500: 245 次/年, 825,000 元
   - 6000: 260 次/年, 900,000 元
   - 6500: 275 次/年, 975,000 元
   - 7000: 290 次/年, 1,050,000 元
✅ 三线图显示循环数和收益趋势
```

**验收标准**:
- [ ] 计算时间 < 15 秒（并发度 3）
- [ ] 所有容量状态显示 ✅
- [ ] 数据与预期基准相符（允许 ±1% 误差）

## 🚀 性能测试

### PT 1: 批量计算性能

**测试环境**: Chrome 浏览器，开发者工具性能面板

**场景**: 计算 10 个容量（并发度 3）

```
预期时间:
  ✅ 总计算时间 < 15 秒
  ✅ 单个容量 < 2 秒
  ✅ UI 响应 < 100 ms
```

**测试步骤**:
```
1. 打开【批量容量对比】Tab
2. 打开浏览器 DevTools → Performance
3. 点击【开始批量容量对比】
4. 点击 Record，等待计算完成
5. 停止 Record，查看报告
   - 关键指标: Long Task < 50ms
   - FPS 应 > 60
```

**验收标准**:
- [ ] 总时间 < 15s
- [ ] 无长任务阻塞
- [ ] 帧率稳定 > 60 FPS
