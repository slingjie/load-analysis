## 🔄 核心数据流

### 流程 1: 批量容量对比流程

```
用户输入
  ↓
  ├─ 储能参数 (StorageParamsPage)
  │   • C-Rate, 效率, DOD, 预留容量
  │   • [确认参数] → 保存到全局状态 (storageParams)
  │
  └─→ 批量容量配置 (StorageCyclesPage)
      ├─ 容量范围: [起始, 步长, 步数]
      ├─ [开始批量容量对比]
      │
      └─→ 并发计算 (并发度 3)
          ├─ POST /api/storage/cycles × N
          ├─ 更新进度条 (0% → 100%)
          └─ 结果保存到 batchResults[]
              {
                capacityKwh: 5500,
                yearEqCycles: 245,
                firstYearProfit: 825000,
                status: 'done'
              }
          
          └─→ BatchCapacityTable 渲染
              ├─ 显示所有容量结果
              ├─ Checkbox 对应 comparisonBasket
              └─ 📊 经济性分析 按钮 → 跳转 Tab 3
```

### 流程 2: 经济性分析流程

```
[用户点击某行 📊 经济性分析 按钮]
  ↓
StorageEconomicsPage (Tab 自动激活)
  ├─ 识别导航参数:
  │   {
  │     capacityKwh: 5500,
  │     firstYearProfit: 825000,
  │     yearEqCycles: 245
  │   }
  │
  ├─ 显示容量卡片: "容量: 5500 kWh, 首年收益: ¥825,000"
  │
  ├─ EconomicsParamsForm 显示
  │   ├─ 快速预设按钮 (保守/标准/乐观)
  │   └─ 手动参数调整 (基础 + 高级)
  │
  ├─ [计算经济性] 按钮
  │   ├─ POST /api/storage/economics
  │   │   {
  │   │     capacity_kwh: 5500,
  │   │     first_year_revenue: 825000,
  │   │     capex_per_wh: 1.0,
  │   │     project_years: 15,
  │   │     om_cost_ratio: 0.015,
  │   │     first_year_decay_rate: 0.03,
  │   │     subsequent_decay_rate: 0.02
  │   │   }
  │   │
  │   └─ 返回结果:
  │       {
  │         staticPaybackYears: 6.7,
  │         irr: 0.152,
  │         npv: 1200000,
  │         annual_cash_flows: [...]
  │       }
  │
  ├─ 结果展示
  │   ├─ 关键指标卡片 (回收期 6.7 年, IRR 15.2%, NPV ¥120 万)
  │   ├─ CashFlowChart (年度现金流 + 累计现金流)
  │   └─ 现金流表格 (年份、收益、成本、净流)
  │
  └─ [← 返回批量对比] → Tab 1 (状态保留)
```

### 流程 3: 对比篮流程

```
[用户勾选 3 个容量的 Checkbox]
  ↓
  └─→ toggleComparison(5500) / toggleComparison(6000) / toggleComparison(6500)
      ↓
      comparisonBasket = Set([5500, 6000, 6500])
      
      └─→ BatchCapacityTable 重新渲染
          ├─ Checkbox 显示已勾选状态
          ├─ 摘要区更新: "已选 3 个"
          └─ [查看对比] 按钮可用

[用户点击 [查看对比] 按钮]
  ↓
ComparisonModal 打开
  ├─ 对比图表 (ComparisonChart)
  │   └─ 四线：循环数、收益、回收期、IRR
  │
  ├─ 对比表格
  │   ├─ 默认显示：容量、循环数、收益
  │   └─ 点击 [显示经济性] 后，额外显示：回收期、IRR
  │
  ├─ [🔄 为全部容量计算经济性]
  │   └─ 批量 POST /api/storage/economics，缓存结果
  │
  └─ [关闭] → Modal 关闭，回到批量对比页面
```

## 🗂️ 全局状态设计

### StorageAnalysisState 结构

```typescript
interface StorageAnalysisState {
  // ==================== M1: 批量容量对比 ====================
  
  // 批量容量结果数组
  batchResults: BatchCapacityItem[];
  // 示例:
  // [
  //   { capacityKwh: 5000, yearEqCycles: 230, firstYearProfit: 750000, ... },
  //   { capacityKwh: 5500, yearEqCycles: 245, firstYearProfit: 825000, ... },
  //   { capacityKwh: 6000, yearEqCycles: 260, firstYearProfit: 900000, ... }
  // ]
  
  // 当前储能参数快照（用于跨 Tab 传递）
  storageParams: StorageParamsTemplate;
  // 示例:
  // {
  //   c_rate: 0.5,
  //   efficiency: 0.95,
  //   dod: 0.9,
  //   reserve_capacity: 0.05,
  //   energy_formula: 'physics'
  // }
  
  // ==================== M2: 经济性分析 ====================
  
  // 当前选中的容量信息（导航参数）
  selectedCapacityForEconomics?: {
    capacityKwh: number;
    firstYearProfit: number;
    yearEqCycles: number;
  };
  // 示例:
  // {
  //   capacityKwh: 5500,
  //   firstYearProfit: 825000,
  //   yearEqCycles: 245
  // }
  
  // 用户配置的经济性参数（全局共享，跨容量复用）
  economicsParams: EconomicsParams;
  // 示例:
  // {
  //   capexPerWh: 1.0,
  //   projectYears: 15,
  //   omCostRatio: 0.015,
  //   firstYearDecayRate: 0.03,
  //   subsequentDecayRate: 0.02
  // }
  
  // 经济性计算结果缓存（容量 → 结果映射）
  economicsResults: Map<number, StorageEconomicsResult>;
  // 示例:
  // {
  //   5500: { staticPaybackYears: 6.7, irr: 0.152, npv: 1200000, ... },
  //   6000: { staticPaybackYears: 6.2, irr: 0.168, npv: 1800000, ... }
  // }
  
  // ==================== M3: 对比篮 ====================
  
  // 已选容量集合（用于批量对比）
  comparisonBasket: Set<number>;
  // 示例: Set([5500, 6000, 6500])
}
```

### Hook 接口

```typescript
interface useStorageAnalysisReturn {
  // 读取状态
  state: StorageAnalysisState;
  
  // 更新方法
  
  // 选择容量进行经济性分析
  selectCapacityForEconomics: (item: BatchCapacityItem) => void;
  
  // 更新经济性参数（部分更新）
  updateEconomicsParams: (params: Partial<EconomicsParams>) => void;
  
  // 保存经济性计算结果
  saveEconomicsResult: (
    capacityKwh: number,
    result: StorageEconomicsResult
  ) => void;
  
  // 切换对比篮（选中/取消）
  toggleComparison: (capacityKwh: number) => void;
  
  // 清空对比篮
  clearBasket: () => void;
  
  // 更新批量结果（可选，用于初始化）
  setBatchResults: (results: BatchCapacityItem[]) => void;
}
```

## 🔌 API 集成详情

### API 1: 批量容量 API

**端点**: `POST /api/storage/cycles`

**请求头**:
```
Content-Type: multipart/form-data
```

**请求体** (FormData):
```
file: <CSV/Excel 文件>          // 负荷数据
capacity_kwh: 5500              // 容量 (kWh)
c_rate: 0.5                     // C-Rate
efficiency: 0.95                // 效率
dod: 0.9                        // 放电深度
reserve_capacity: 0.05          // 预留容量
energy_formula: 'physics'       // 能量公式
```

**响应**:
```json
{
  "status": "success",
  "data": {
    "capacity_kwh": 5500,
    "year_eq_cycles": 245,
    "profit_net": 825000,
    "profit_gross": 900000,
    "profit_months": [...],
    "profit_days": [...],
    "cycle_summary": {...}
  }
}
```

**前端集成**:
```typescript
const handleBatchCompute = async () => {
  const capacities = [5000, 5500, 6000];
  const results = [];
  
  // 并发度 3
  for (let i = 0; i < capacities.length; i += 3) {
    await Promise.all(
      capacities.slice(i, i + 3).map(async capacity => {
        const formData = new FormData();
        formData.append('file', loadFile);
        formData.append('capacity_kwh', capacity);
        formData.append('c_rate', storageParams.c_rate);
        // ... 其他参数
        
        const response = await fetch('/api/storage/cycles', {
          method: 'POST',
          body: formData
        });
        const data = await response.json();
        results.push({
          capacityKwh: capacity,
          yearEqCycles: data.data.year_eq_cycles,
          firstYearProfit: data.data.profit_net,
          status: 'done'
        });
      })
    );
  }
};
```

## 🎯 Tab 切换与状态保留机制

### 切换规则

```
StorageParamsPage ↔ StorageCyclesPage ↔ StorageEconomicsPage
     (Tab 1)             (Tab 2)              (Tab 3)
      ↓                   ↓                    ↓
  state.storageParams  state.batchResults   state.selectedCapacityForEconomics
                       state.comparisonBasket  state.economicsParams
                                           state.economicsResults
```

### 状态持久化

| 状态字段 | 作用域 | 生命周期 | 持久化 |
|---------|--------|---------|--------|
| `storageParams` | 全局 | 用户会话 | ✅ localStorage |
| `batchResults` | Tab 2-3 | 用户会话 | ✅ localStorage |
| `economicsParams` | Tab 3 | 用户会话 | ✅ localStorage |
| `economicsResults` | Tab 3 | 用户会话 | ✅ Map (内存) |
| `comparisonBasket` | Tab 2-3 | 当前会话 | ❌ (内存) |
| `selectedCapacityForEconomics` | Tab 3 | 导航时刻 | ❌ (导航参数) |

**持久化策略**:
```typescript
// useStorageAnalysis Hook 中
useEffect(() => {
  // 保存到 localStorage
  localStorage.setItem('storageParams', JSON.stringify(state.storageParams));
  localStorage.setItem('batchResults', JSON.stringify(state.batchResults));
}, [state.storageParams, state.batchResults]);

// 初始化时恢复
useEffect(() => {
  const saved = localStorage.getItem('storageParams');
  if (saved) setStorageParams(JSON.parse(saved));
}, []);
```

## 🔒 错误处理与异常流程

### 错误场景

#### 场景 1: 网络错误

```
[用户点击 开始批量容量对比]
  ↓
POST /api/storage/cycles 失败
  ↓
异常捕获
  ├─ 显示错误提示: "网络连接失败，请重试"
  ├─ 保留已成功的结果（部分结果）
  └─ 记录错误日志
```

**实现**:
```typescript
try {
  const response = await fetch('/api/storage/cycles', { ... });
  if (!response.ok) throw new Error(`HTTP ${response.status}`);
  const data = await response.json();
} catch (error) {
  console.error('API Error:', error);
  toast.error('计算失败，请检查网络或参数');
  // 状态仍保留已成功的结果
}
```

#### 场景 2: 参数校验错误

```
用户输入参数 → 校验失败 → 显示红色提示文本 → 禁用提交按钮
```

**实现**:
```typescript
const validateParams = (params: EconomicsParams) => {
  const errors = [];
  if (params.capexPerWh <= 0) errors.push('投资成本必须 > 0');
  if (params.projectYears < 1) errors.push('项目年限必须 ≥ 1');
  return errors;
};

// 在表单中使用
const canSubmit = validateParams(economicsParams).length === 0;
```

#### 场景 3: 超时

```
API 请求超过 30 秒 → 自动超时 → 显示重试按钮
```

**实现**:
```typescript
const fetchWithTimeout = (url, options, timeout = 30000) => {
  return Promise.race([
    fetch(url, options),
    new Promise((_, reject) =>
      setTimeout(() => reject(new Error('Request timeout')), timeout)
    )
  ]);
};
```

### 2. 缓存机制

```typescript
// 缓存经济性结果，避免重复计算
const economicsResultsCache = new Map<number, StorageEconomicsResult>();

const computeEconomics = async (capacity) => {
  if (economicsResultsCache.has(capacity)) {
    return economicsResultsCache.get(capacity);
  }
  const result = await fetch(...);
  economicsResultsCache.set(capacity, result);
  return result;
};
```
