# 项目评估报告数据为空问题 - 诊断指南

## 问题现象

生成的报告中数据全部显示为 0 或"当前数据暂不足以给出可靠结论"。

## 根本原因

前端未正确传递完整数据给后端，导致 DeepSeek 无法生成有意义的报告内容。

## 数据依赖关系

报告生成需要以下数据源：

| 数据项 | 来源页面 | 必需性 | 影响的报告章节 |
|--------|---------|--------|--------------|
| **负荷数据** | Load Analysis | 强烈推荐 | 第 2 章（负荷特征）|
| **储能配置** | Storage Cycles | 必需 | 第 4 章（配置）、第 5 章（收益）|
| **储能测算结果** | Storage Cycles | 必需 | 第 1 章（结论）、第 5 章（收益）|
| **数据质量报告** | Load Analysis | 推荐 | 第 1 章（数据完整性）|
| **TOU 配置** | Price Editor | 推荐 | 第 3 章（电价策略）|

## 正确的使用流程

### 步骤 1：上传负荷数据

1. 点击"上传负荷文件"按钮
2. 选择 Excel 或 CSV 格式的负荷数据
3. 等待解析完成，确认看到：
   - ✓ 负荷数据已上传
   - ✓ 质量报告已生成

### 步骤 2：运行储能测算

1. 切换到"Storage Cycles"页面
2. 配置储能参数：
   - 储能容量（MWh）
   - 储能功率（MW）
   - 充放电效率
   - SOC 范围
3. 点击"Calculate"按钮
4. 等待计算完成，确认看到：
   - ✓ 储能测算已完成
   - 收益数据、循环次数等结果

### 步骤 3：生成项目评估报告

1. 切换到"Project Summary"页面
2. 填写项目信息：
   - 项目名称（必填）
   - 项目地点（可选）
   - 评估周期（自动从负荷数据获取）
3. 检查"数据状态检查"区域，确认：
   - ✓ 负荷数据已上传
   - ✓ 质量报告已生成
   - ✓ 储能测算已完成
4. 点击"生成项目评估报告"
5. 如有数据缺失，会弹出警告对话框
6. 等待 10-30 秒生成完成

## 验证数据是否正确传递

### 方法 1：查看浏览器控制台

按 F12 打开开发者工具，在 Console 标签中查看：

```javascript
// 检查 loadMeta
console.log('负荷元数据:', loadMeta);

// 检查 storageCyclesResult
console.log('储能测算结果:', storageCyclesResult);

// 检查 storageCyclesPayload
console.log('储能配置参数:', storageCyclesPayload);
```

如果这些变量为 `null` 或 `undefined`，说明数据未准备好。

### 方法 2：查看请求数据

在 Network 标签中：

1. 找到 `/api/deepseek/project-summary` 请求
2. 查看 Request Payload
3. 确认 `load_profile`、`storage_config`、`storage_results` 字段不为空

## 常见问题排查

### 问题 1：报告中负荷数据全为 0

**原因**：未上传负荷数据或上传失败

**解决**：
1. 检查 Load Analysis 页面是否显示"负荷数据已上传"
2. 重新上传负荷文件
3. 确认文件格式正确（包含 timestamp 和 load 列）

### 问题 2：报告中储能收益、循环次数为 0

**原因**：未运行储能测算或测算失败

**解决**：
1. 切换到 Storage Cycles 页面
2. 确认已填写所有必需参数
3. 点击 Calculate 并等待完成
4. 检查是否有错误提示

### 问题 3：报告生成但内容都是"数据不足"

**原因**：数据已准备，但前端未正确构建请求

**解决**：
1. 刷新页面（Ctrl+Shift+R）
2. 重新上传数据并测算
3. 检查浏览器控制台是否有 JavaScript 错误

### 问题 4：生成报告时提示 404 错误

**原因**：后端服务未运行或环境变量未配置

**解决**：
1. 确认后端在 http://localhost:8000 运行
2. 检查 `.env.local` 中的 `DEEPSEEK_API_KEY` 已配置
3. 重启后端服务：
   ```powershell
   $env:DEEPSEEK_API_KEY='your_key_here'
   uvicorn backend.app:app --reload
   ```

## 测试用例

可以使用以下 Python 脚本测试 API 是否正常：

```python
import requests

url = 'http://localhost:8000/api/deepseek/project-summary'
data = {
    'project_name': '测试项目',
    'period_start': '2025-01-01',
    'period_end': '2025-01-31',
    'load_profile': {
        'avgLoad': '约 1200.50 kW',
        'peakLoad': '约 2500.00 kW',
        'valleyLoad': '约 400.00 kW',
    },
    'storage_config': {
        'capacityMWh': '4.00',
        'powerMW': '2.00',
    },
    'storage_results': {
        'effectiveAnnualCycles': '约 280.0 次/年',
        'firstYearRevenueDetail': '约 45.50 万元',
    }
}

response = requests.post(url, json=data)
print(response.status_code)
print(response.json()['markdown'][:500])
```

如果这个测试成功，说明后端正常，问题在前端数据传递。

## 最佳实践

1. **按顺序准备数据**：Load Analysis → Storage Cycles → Project Summary
2. **确认数据状态**：每一步完成后检查绿色勾选标记
3. **保存重要配置**：储能配置可以保存，避免重复输入
4. **验证报告内容**：生成后检查关键数值是否合理
