## 阶段 1：后端核心开发（3 天）

### Day 1: 能量分配算法实现

#### 🎯 目标
实现按价格优先分配放电能量的核心算法

#### 📋 任务清单

- [ ] **Task 1.1**：创建 `_allocate_discharge_by_price()` 函数
  - **位置**：`backend/services/cycles.py` 第 1500 行附近（`compute_profit_summary_step15` 之前）
  - **输入**：放电时段 DataFrame、最大可放电量、储能配置、电价序列
  - **输出**：分配后的 DataFrame，含 `e_out_allocated` 列
  - **核心逻辑**：
    ```python
    1. 复制 DataFrame，添加 price 列（从 price_series 映射）
    2. 按 price 降序排列
    3. 初始化 remaining_energy = max_discharge_energy
    4. 遍历排序后的点：
       a. 计算该点最大放电功率（受变压器和 C-Rate 约束）
       b. 分配能量 = min(最大功率 × 0.25, remaining_energy)
       c. 更新 remaining_energy
    5. 返回分配结果
    ```
  - **约束检查**：
    - 变压器容量：`limit_kw`
    - 电池倍率：`battery_capacity × c_rate`
    - 15 分钟时长：`× 0.25 小时`

- [ ] **Task 1.2**：添加单元测试
  - **文件**：`backend/tests/test_cycles_price_priority.py`（新建）
  - **测试用例**：
    1. `test_price_priority_basic()`：验证基础排序逻辑
    2. `test_transformer_limit()`：验证变压器约束
    3. `test_battery_crate_limit()`：验证 C-Rate 约束
    4. `test_insufficient_energy()`：验证电量不足场景
    5. `test_equal_prices()`：验证电价相同时与 sequential 一致

- [ ] **Task 1.3**：本地验证
  - 运行单元测试：`pytest backend/tests/test_cycles_price_priority.py -v`
  - 使用 `simulate_calc.py` 手工验证简单场景

### C. 术语表

| 术语 | 英文 | 说明 |
|------|------|------|
| **尖段** | Super Peak | 电价最高的时段，通常为晚高峰 19-21 点 |
| **峰段** | Peak | 次高电价时段，通常为早晚通勤时段 |
| **时序放电** | Sequential Discharge | 按时间顺序线性分配能量的策略 |
| **尖段优先** | Price-Priority | 按电价高低优先分配能量的策略 |
| **C-Rate** | C倍率 | 电池充放电倍率，如 0.5C 表示 2 小时充满 |
| **DoD** | Depth of Discharge | 放电深度，如 90% 表示可用电量为总容量的 90% |
