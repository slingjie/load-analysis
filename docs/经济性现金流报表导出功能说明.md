# 经济性现金流报表导出功能说明

## 功能概述

在储能经济性测算页面（Economics）新增了"导出经济性报表"按钮，用户可以一键导出多年期经济性现金流明细报表（CSV格式）。

## 使用方法

1. **进入经济性测算页面**
   - 在主应用中切换到 "Economics" 标签页

2. **填写测算参数**
   - 首年收益（必填）
   - 项目年限（默认15年）
   - 装机容量（必填）
   - CAPEX单价（默认1.0元/Wh）
   - 年运维成本（默认0.2元/Wh）
   - 首年衰减率（默认3%）
   - 后续衰减率（默认2%）
   - 电芯更换年份（可选）
   - 电芯更换成本（可选）
   - 用户收益分成比例（可选）

3. **点击"导出经济性报表"按钮**
   - 系统将自动计算经济性指标
   - 生成包含年度现金流明细和经济性指标汇总的ZIP文件
   - 浏览器会自动下载生成的ZIP文件

## 报表内容

### 1. 年度现金流明细（CSV）

包含以下列：
- **年份**：第几年（1..N）
- **原年度总收益(元)**：用户分成前的总收益（未扣用户分成）
- **用户方年度收益(元)**：用户分成部分（原总收益 × 分成比例）
- **项目方年度收益(元)**：项目方分成部分（原总收益 - 用户分成）
- **储能放电量(kWh)**：当年储能系统的放电量（考虑衰减）
- **运维成本(元)**：当年运维成本
- **电芯更换成本(元)**：当年电芯更换成本（无更换则为0）
- **年度净现金流(元)**：项目方年度收益 - 运维成本 - 更换成本
- **累计净现金流(元)**：从项目开始到当年的累计净现金流

**重要说明：**
- 如果设置了用户分成比例（如30%），系统会自动计算原年度总收益和用户方收益
- 项目方年度收益 = 原年度总收益 × (1 - 分成比例)
- 储能放电量会随年份衰减，并在换电芯年份重置为首年水平

### 2. 经济性指标汇总（CSV）

包含以下指标：
- **总投资(CAPEX)**：项目总投资额（元）
- **内部收益率(IRR)**：项目的内部收益率（%）
- **静态回收期**：投资回收年限（年）
- **项目末累计净现金流**：项目结束时的累计净现金流（元）
- **静态平均度电成本(LCOE)**：度电成本（元/kWh）
- **年均发电能量**：年均放电量（kWh）
- **年均收益**：年均收益（元）
- **度电平均收益**：平均度电收益（元/kWh）
- **经济可行性比值**：度电收益/度电成本
- **筛选结论**：pass/fail（基于经济可行性比值判断）

**示例数据：**
```

静态平均度电成本(LCOE),0.1545,元/kWh
年均发电能量,43161.22,kWh
年均收益,90892.7,元
度电平均收益,2.1059,元/kWh
经济可行性比值,13.6339,-
筛选结论,pass,-
```

## 技术实现

### 后端接口

**POST** `/api/storage/economics/export`

**请求参数：**（与 `/api/storage/economics` 相同）
```json
{
  "first_year_revenue": 100000,
  "first_year_energy_kwh": 50000,
  "project_years": 15,
  "annual_om_cost": 0.2,
  "first_year_decay_rate": 0.03,
  "subsequent_decay_rate": 0.02,
  "capex_per_wh": 1.0,
  "installed_capacity_kwh": 100,
  "cell_replacement_cost": 0.3,
  "cell_replacement_year": 8
}
```

**响应：**
```json
{
  "excel_path": "经济性现金流报表_20241213_082026.zip",
  "message": "经济性现金流报表生成成功"
}
```

### 文件下载

生成的ZIP文件存放在后端 `outputs/` 目录，可通过以下URL访问：
```
http://localhost:8002/outputs/经济性现金流报表_20241213_082026.zip
```

前端会自动构造完整URL并触发浏览器下载。

## 与储能收益报表的区别

| 特性 | 储能收益报表（Storage Cycles） | 经济性现金流报表（Economics） |
|------|-------------------------------|------------------------------|
| **数据来源** | `/api/storage/cycles` 接口 | `/api/storage/economics` 接口 |
| **时间跨度** | 单年（12个月） | 多年（1-30年） |
| **核心内容** | 每日/每月充放电收益、度电利润 | 年度现金流、IRR、回收期 |
| **适用场景** | 分析储能系统单年运营效果 | 评估项目长期经济可行性 |
| **包含指标** | 充电成本、放电收入、净收益、等效循环次数 | 年度收益、运维成本、电芯更换、累计现金流、IRR、静态回收期 |

## 常见问题

### Q1: 为什么需要单独的导出按钮？

A: 经济性测算和储能收益测算是两个不同的分析维度。经济性测算关注长期财务可行性（IRR、回收期），而储能收益测算关注短期运营效果。单独的导出按钮便于用户快速获取经济性分析报表，无需先进行完整测算。

### Q2: 报表中的"用户分成比例"如何影响结果？

A: 如果设置了用户分成比例（例如30%），系统会自动从首年总收益中扣除用户分成，只计算项目方的经济性指标。例如：
- 首年总收益：100,000元
- 用户分成30%：30,000元
- 项目方首年收益：70,000元（用于IRR计算）

### Q3: 电芯更换如何影响现金流？

A: 在指定的更换年份（如第8年），系统会：
1. 在该年度扣除电芯更换成本（影响年度净现金流）
2. 从该年开始，收益重置为首年水平（无衰减）
3. 后续年份按新的衰减曲线计算收益

### Q4: IRR为什么会显示"无法收敛"？

A: 当项目无法在合理时间内回收投资时，IRR计算可能无法收敛。常见原因：
- 首年收益过低
- CAPEX过高
- 运维成本过高
- 衰减率过高

建议调整参数使项目经济可行。

### Q5: 如何解读"经济可行性比值"？

A: 经济可行性比值 = 度电平均收益 ÷ 静态平均度电成本
- **≥ 1.5**：项目经济可行性较好（默认阈值）
- **< 1.5**：项目经济可行性不足，建议优化参数
