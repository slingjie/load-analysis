目前已经计算了首年的收益，后续想开发储能经济性测算的功能，主要功能为测算当前储能配置的电站的 IRR 和回收年限，但是不用太复杂，主要有静态回收的相关计算即可，请查看我的需求，我们来讨论和补充。

## 1. 首年收益口径与最少输入项

- “首年收益”的具体含义：
	- 只是电价套利的收入，**已扣除充电电费支出**，但**尚未扣除运维等其他成本**。
	- 后续经济性测算中，将在此基础上扣减年运维成本等，得到年度净现金流。

- “最少输入项”是哪些：
	- 年运维成本：每年的固定运维支出，用于从首年收益中扣减得到年度净现金流。
	- 项目年限：用于生成整个评估期的年度现金流序列（如 10/15/20 年）。
	- 年衰减率：首年收益按年递减的比例，用于模拟电价、利用小时、容量退化等因素。
	- 单 Wh 投资：根据当前储能配置容量，计算项目总投资 CAPEX。
	- 更换电芯成本：电芯更换当年的一次性投入成本。
	- 更换电芯时间：到达该年份时触发电芯更换，经济性逻辑为：
		- 一方面增加一笔“更换电芯成本”的一次性现金流支出；
		- 另一方面“收益曲线重新起一个首年点并重新按衰减走”，即更换后第一年的收益重置为新的首年收益，之后继续按同一衰减率递减。

报表/前端上期望输出：IRR、静态回收期、简单的年度现金流表和对应图表；报表中还需要展示在项目年限内每年收益随衰减变化的图表。

## 2. 计算逻辑（简要）

### 2.1 年度收益与净现金流

- 记首年收益为 R₁（已扣电费、未扣运维）。
- 若不考虑电芯更换，则：
	- 第 1 年：
		- 年收益₁ = R₁
		- 年净现金流₁ = 年收益₁ − 年运维成本
	- 第 t 年（t ≥ 2）：
		- 年收益ₜ = R₁ × (1 − 年衰减率)^(t−1)
		- 年净现金流ₜ = 年收益ₜ − 年运维成本

- 若存在电芯更换：
	- 更换电芯当年（设为第 T 年）：
		- 年净现金流_T = 年收益_T − 年运维成本 − 更换电芯成本
	- 更换后：
		- 将更换后第 1 年收益视为新的首年收益 R′₁（可默认等于初始 R₁），
		- 后续年份按同一年衰减率从 R′₁ 重新递减计算年收益和净现金流。

### 2.2 静态回收期

- 不考虑折现，逐年累加净现金流：
	- 累计净现金流_t = Σ(年净现金流_i)，i = 1..t
	- 找到首次满足“累计净现金流_t ≥ 总投资 CAPEX”的年份 t₀；
	- 若需要更精确，可在 t₀ 年内做线性插值，得到带小数的回收年限。

### 2.3 IRR（内部收益率）

- 现金流序列构造：
	- 第 0 年：CF₀ = −总投资 CAPEX（由单 Wh 投资 × 当前储能配置容量得到）；
	- 第 1~N 年：CFₜ = 对应年份的年净现金流ₜ（包含运维和电芯更换影响）。

- IRR 定义：寻找收益率 r 使得净现值为 0：
	$$
	\sum_{t=0}^{N} \frac{CF_t}{(1 + r)^t} = 0
	$$

- 实现上可使用标准数值算法（如牛顿迭代）或现有 IRR 库函数计算 r，并将其作为项目 IRR 输出。

## 4. 静态度电成本与投决结论的关系

### 4.1 静态对比的作用边界

结论：

- 单纯用“静态度电成本 vs 度电收益”对比，不能作为最终投决依据，但可以作为项目的前期经济性筛选工具，用于判断项目“大致有没有戏”。

静态指标定义：

- 静态度电成本 = 一次性投资 CAPEX ÷ 全寿命放电电量；
- 度电收益 = 年（或全寿命）总收益 ÷ 放电电量；
- 若 度电收益 > 静态度电成本 → 从静态角度“看起来能赚钱”；
- 若 度电收益 ≤ 静态度电成本 → 项目大概率赚不到钱。

静态对比适合用于：

- 早期立项 / 快速筛选项目；
- 不同技术路线、不同寿命方案之间的初步对比；
- 向客户 / 领导说明经济性量级（如“单度电大概能赚多少钱”）。

### 4.2 为什么不能直接用于投决

静态度电成本 / 度电收益对比存在以下缺口：

- 未考虑时间价值（折现），可能高估项目价值；
- 未纳入全部 OPEX 及电池更换成本；
- 未考虑利用小时、电量不达预期等运营风险；
- 未体现容量退化和阶段性性能下降；
- 未考虑税收、折旧、融资结构等对 IRR 的重要影响。

因此：

- 静态对比“能赚钱” ≠ 财务模型 IRR 一定合格，特别是边缘项目；
- 正式“是否值得投资”的结论，应以 IRR、静态回收期和现金流曲线为核心指标。

### 4.3 实务经验规则

- 规则 1：负筛选（快速否决）
	- 若 度电收益 ≤ 静态度电成本 → 基本可判定项目经济性明显不足，无需再做详细模型。

- 规则 2：正向初筛（值得深算）
	- 若 度电收益 ≥ 静态度电成本 × 1.5–2 倍 → 经济性“看起来有戏”，值得进入详细财务测算（IRR / NPV / 回收期）。

注意：

- 上述规则只用于判断“是否值得做详细测算”，并非可以直接得出“可以投资”的结论。

### 4.4 推荐评估流程

在售前 / 方案阶段，可采用三步评估流程：

1. 静态快速筛选：
	 - 利用静态度电成本 vs 度电收益，对项目进行初筛，剔除明显不具经济性的项目；
2. 简化 LCOS + 粗 IRR：
	 - 加入 OPEX、电芯更换、退化等要素，基于统一折现率估算简化 LCOS 和粗略 IRR / 回收期；
3. 完整财务模型：
	 - 构建分年度现金流模型，计算 IRR / NPV、静态 / 动态回收期，并做敏感性分析，用于正式投决。

本次开发的“IRR + 静态回收期 + 年度现金流表和图”，对应于第 2 步到第 3 步之间的简化版模型，为“是否值得投资”提供量化依据；重大项目仍建议在此基础上构建完整财务模型进行复核。

## 5. 推荐默认参数与判定规则

为便于快速评估和统一口径，建议在前端 / 配置中提供以下默认参数（用户可修改）：

- 项目年限默认值：
	- 建议默认 15 年（常见工商业储能项目评估周期，可根据具体业务调整为 10–20 年范围）。

- 年衰减率默认值：
	- 建议默认 1%–2% / 年（用于模拟电价、利用小时和容量退化的综合影响，具体可按电芯技术路线微调）。

- 年运维成本默认值：
	- 可按“总投资的一定比例”或“按单位功率 / 容量”预置一个经验值（例如 1%–2% 的 CAPEX / 年），支持用户覆盖。

- 折现率（用于 IRR 对比的参考基准）：
	- 虽然 IRR 计算本身不依赖预设折现率，但可在报表中给出对比基准，例如 8%–10% 作为资金成本 / 目标回报率区间。

- IRR 合格线建议：
	- 结合企业资金成本和风险偏好，可建议：
		- IRR ≥ 8%：经济性基本可接受；
		- IRR ≥ 10%：经济性较好；
		- IRR ≥ 12%：经济性优秀（视行业和区域具体情况可调整）。

- 静态回收期参考阈值：
	- 一般要求静态回收期 < 项目年限的一半（例如项目年限 15 年，静态回收期控制在 7–8 年以内较为稳健）。

综合判定规则示例：

- 若满足：
	- IRR ≥ 目标收益率（如 8% 或 10%），且
	- 静态回收期小于项目年限的一半，且
	- 静态度电收益明显高于静态度电成本（≥ 1.5–2 倍），
	- 则可认为该储能项目在当前假设下“经济性较好，值得投资或进一步深入评估”。

- 若 IRR 较低或静态回收期接近 / 超过项目年限，则需要谨慎评估假设条件（电价、利用小时、CAPEX 等），并在必要时调整方案或放弃项目。


## 6. 开发计划

### 阶段一：后端经济性核心模型与接口（静态回收 + IRR + 年度现金流）

1. **后端：新增经济性数据模型与服务骨架**
   - 新增 `backend/services/economics.py`，承载 IRR、静态回收期、年度现金流等计算逻辑（仅规划结构，不依赖具体 Web 框架）。
   - 在 `backend/schemas.py` 中新增模型：
     - `StorageEconomicsInput`：字段包括  
       - `first_year_revenue: float`（首年收益 R₁，已扣电费、未扣运维）  
       - `project_years: int`（项目年限）  
       - `annual_om_cost: float`（年运维成本）  
       - `annual_decay_rate: float`（年衰减率，0–1）  
       - `capex_per_wh: float`（单 Wh 投资，元/Wh）  
       - `installed_capacity_kwh: float`（当前储能配置容量，kWh）  
       - `cell_replacement_cost: float | None`（更换电芯成本，可选）  
       - `cell_replacement_year: int | None`（更换电芯时间，第 N 年，可选）  
       - `second_phase_first_year_revenue: float | None`（更换后新的首年收益 R′₁，可选，默认与 R₁ 相同）
     - `YearlyCashflowItem`：字段包括  
       - `year_index: int`（第几年度，1..N）  
       - `year_revenue: float`（年度收益）  
       - `annual_om_cost: float`（当年运维成本）  
       - `cell_replacement_cost: float`（当年电芯更换支出，如无则为 0）  
       - `net_cashflow: float`（年度净现金流）  
       - `cumulative_net_cashflow: float`（累计净现金流）
     - `StorageEconomicsResult`：字段包括  
       - `capex_total: float`（总投资 CAPEX）  
       - `irr: float | None`（内部收益率，如无法收敛则为 null）  
       - `static_payback_years: float | None`（静态回收期，可带小数）  
       - `final_cumulative_net_cashflow: float`（项目周期末累计净现金流）  
       - `yearly_cashflows: list[YearlyCashflowItem]`（年度现金流序列）

2. **后端：规划经济性计算服务函数**
   - 在 `backend/services/economics.py` 中规划函数（仅定义职责与入参出参）：
     - `build_cashflows(input: StorageEconomicsInput) -> list[YearlyCashflowItem]`  
       - 按文档 2.1 的收益递减逻辑与电芯更换规则，生成每年收益与净现金流。
     - `compute_static_payback(cashflows: list[YearlyCashflowItem], capex_total: float) -> float | None`  
       - 按 2.2 定义，逐年累加净现金流找到首次回本年份并线性插值。
     - `compute_irr(cashflows: list[YearlyCashflowItem], capex_total: float) -> float | None`  
       - 构造现金流序列 `[CF0, CF1..CFN]`，实现 IRR 数值算法或调用库函数。

3. **后端：新增经济性测算 API 接口**
   - 在 `backend/app.py` 中新增路由（示例）：
     - `POST /api/storage/economics`
       - 请求体：`StorageEconomicsInput`（JSON）。
       - 处理逻辑（规划）：  
         - 计算 `capex_total = capex_per_wh * installed_capacity_kwh * 1000`（kWh -> Wh）。  
         - 调用 `build_cashflows` 得到 `yearly_cashflows`。  
         - 调用 `compute_static_payback`、`compute_irr` 得到核心经济性指标。  
         - 组装 `StorageEconomicsResult` 返回。
   - 本阶段经济性接口假定“首年收益 R₁ 已由其他模块给出”，不在此接口内部重新计算收益。

4. **后端：现有收益结果对接规划**
