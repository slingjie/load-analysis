# 项目评估报告生成功能 - 使用指南

## 功能概述

基于 DeepSeek 大模型，自动从负荷数据、TOU 配置和储能测算结果中生成专业的项目评估报告（面向业主方）。

报告采用标准 7 章结构：
1. 项目概况与评估结论
2. 用户负荷特征与典型运行情况
3. 当前 TOU 配置与运行策略
4. 储能电站配置与模拟方式
5. 储能充放次数与收益评估
6. 风险点与优化建议
7. 附录：数据与参数表

## 前置准备

### 1. 配置 DeepSeek API Key

在项目根目录创建或编辑 `.env.local` 文件：

```env
DEEPSEEK_API_KEY=your_deepseek_api_key_here
```

**获取步骤：**
1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/)
2. 注册并登录
3. 在 API Keys 页面创建密钥
4. 复制密钥到 `.env.local`

### 2. 准备数据

为了生成完整报告，建议按以下顺序准备数据：

1. **上传负荷数据**（必需）
   - 点击"上传负荷文件"按钮
   - 选择 Excel 或 CSV 格式的负荷数据
   - 等待解析完成

2. **配置 TOU 电价**（可选）
   - 切换到"Price Editor"页面
   - 设置各时段电价

3. **运行储能测算**（推荐）
   - 切换到"Storage Cycles"页面
   - 配置储能参数（容量、功率、效率等）
   - 点击"Calculate"生成测算结果

## 使用步骤

### 1. 进入项目总结页面

点击顶部导航栏的 **"Project Summary"** 按钮。

### 2. 填写项目信息

- **项目名称**（必填）：例如"某某医院储能项目"
- **项目地点**（可选）：例如"安徽省某市"
- **评估周期开始**（必填）：会自动从负荷数据获取
- **评估周期结束**（必填）：会自动从负荷数据获取

### 3. 检查数据状态

页面会显示数据准备情况：
- ✓ 负荷数据已上传
- ✓ 质量报告已生成
- ✓ 储能测算已完成

**提示：** 即使某些数据未准备，也可以生成报告，但内容会相对简略。

### 4. 生成报告

点击 **"生成项目评估报告"** 按钮。

- 生成过程约需 10-30 秒
- 页面会显示进度提示
- 请勿关闭页面或刷新

### 5. 查看和导出报告

生成成功后，页面会展示：

1. **关键摘要**（蓝色框）
   - 首年总收益
   - 日均循环次数
   - 利用小时数
   - 数据完整性

2. **完整报告预览**
   - 7 章完整内容
   - Markdown 格式
   - 可滚动查看

3. **导出选项**
   - **复制 Markdown**：一键复制到剪贴板，可粘贴到 Word/Typora
   - **下载 Markdown**：下载为 `.md` 文件

## 使用技巧

### 数据完整性优化

为获得最佳报告质量，建议：

1. **负荷数据周期**：至少覆盖完整的一个月，最好包含多个季节
2. **储能测算**：完成至少一次测算，系统会自动提取关键指标
3. **TOU 配置**：设置完整的分时电价，报告会分析电价与负荷匹配度

### 二次编辑建议

生成的 Markdown 报告可以：

1. 在 Typora/VS Code 等编辑器中打开
2. 补充具体项目细节（如投资金额、合同条款）
3. 调整措辞以符合特定业主的风格
4. 插入项目现场照片、设计图纸等
5. 导出为 PDF 或 Word 格式发送给业主

### 多次生成

- 可以多次生成报告，每次都会获得新的报告 ID
- 如果修改了储能配置或负荷数据，建议重新生成
- 报告内容会根据最新数据动态调整

## 故障排查

### 问题 1：提示"DeepSeek API Key 未配置"

**解决方案：**
1. 检查 `.env.local` 文件是否存在且包含 `DEEPSEEK_API_KEY`
2. 确认环境变量名拼写正确（全大写）
3. 重启后端服务使配置生效

### 问题 2：生成超时或失败

**可能原因：**
- 网络连接不稳定
- DeepSeek API 服务繁忙
- API Key 额度不足或过期

**解决方案：**
1. 检查网络连接
2. 稍后重试
3. 登录 DeepSeek 平台检查 API Key 状态和余额
4. 查看浏览器控制台和后端日志获取详细错误信息

### 问题 3：报告内容不准确或缺失

**解决方案：**
1. 确认负荷数据和储能测算已完成
2. 检查数据质量（缺失率、异常值）
3. 报告生成后人工复核关键数值
4. 必要时二次编辑补充

## 技术说明

### 数据隐私

- 所有数据通过 HTTPS 传输到 DeepSeek API
- 不建议在公开环境使用敏感项目数据
- 可考虑在内网部署或使用脱敏数据测试

### API 调用成本

- 每次生成约消耗 8000-10000 tokens（根据数据量）
- 建议在确认数据无误后再生成，避免频繁调用
- DeepSeek 定价详见官网：https://platform.deepseek.com/

### 自定义扩展

如需定制报告内容，可修改：

- **后端 Prompt**：`backend/services/deepseek_summary.py` 中的 `build_deepseek_prompt()` 函数
- **报告模板**：`docs/DeepSeek项目评估报告模板.md`
- **数据提取**：`backend/services/deepseek_summary.py` 中的 `extract_summary_data()` 函数
